Website Tamper-proof

Locks a site's files AND directories so nothing — not even PHP-FPM, a compromised upload, or root without first disabling this — can modify or plant new files, using the filesystem's immutable attribute. Folders commonly written to at runtime (uploads, cache, storage, logs, tmp, image) are left unlocked so a protected site keeps working normally — new product photo uploads still work; existing files can't be replaced or new code files planted anywhere else. Turn this off before you intend to edit the site's files yourself — disabling requires typing the domain name to confirm.
